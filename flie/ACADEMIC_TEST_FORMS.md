# 📑 ส่วนที่ 2: แบบสอบถามประเมินความพึงพอใจและการยอมรับของผู้ใช้งาน (User Acceptance Questionnaire)

### คำชี้แจง
แบบสอบถามนี้มีวัตถุประสงค์เพื่อประเมินความพึงพอใจและการยอมรับการใช้งาน **ระบบตรวจสอบประวัติอาชญากรรมและหมายจับอัตโนมัติ (C.I.A.S.) ผ่าน Telegram Bot Direct Chat** โดยเจ้าหน้าที่ผู้ปฏิบัติงาน ขอความกรุณาทำเครื่องหมาย $\checkmark$ ลงในช่องที่ตรงกับความคิดเห็นของท่านมากที่สุด

**ระดับการประเมินค่า (5-Point Likert Scale):**  
$5$ = มากที่สุด, $4$ = มาก, $3$ = ปานกลาง, $2$ = น้อย, $1$ = น้อยที่สุด
