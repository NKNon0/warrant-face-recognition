# 📘 รายงานสรุปสถาปัตยกรรมและการพัฒนาระบบ AI ตรวจสอบประวัติอาชญากรรม (Warrant & AI Recognition System)

---

## 1. 🔬 สรุปการประเมินและเปรียบเทียบ AI ทุกโมเดลตั้งแต่เริ่มต้นโปรเจกต์ (AI Models Evaluation)

ตลอดระยะเวลาการพัฒนาระบบ ได้มีการทดลองและประเมินประสิทธิภาพของโมเดล AI ในแต่ละด้านอย่างละเอียด ดังนี้:

### 1.1 👤 การจดจำใบหน้าบุคคล (Face Recognition Engine)
* **โมเดลที่เคยทดลอง:**
  * **DeepFace (VGG-Face, Facenet, OpenFace):** ความแม่นยำสูงในภาพถ่ายสตูดิโอ แต่ใช้เวลาประมวลผลต่อภาพนาน (2-4 วินาที) และต้องการ GPU สเปกสูง
  * **InsightFace (ArcFace 512D Vector / ResNet50 - `buffalo_l`):** **(เลือกใช้เป็นโมเดลหลัก)**
* **ผลสรุปที่เลือกใช้:** **InsightFace (ArcFace)**
  * **เหตุผล:** สามารถสกัดจุดเด่นของใบหน้าเป็นเวกเตอร์ 512 มิติ (512D Embedding Array) ได้รวดเร็วในระดับมิลลิวินาที สามารถคำนวณความคล้ายคลึงทางคณิตศาสตร์ด้วย **Cosine Similarity Math** กับฐานข้อมูล `face_profiles` ได้รวดเร็ว และทนทานต่อสภาวะแสง มุมกล้อง และการเอียงของใบหน้า

---

### 1.2 🚗 การตรวจจับและอ่านป้ายทะเบียนรถ (License Plate Recognition - ALPR)
* **โมเดลที่เคยทดลอง:**
  * **EasyOCR / PaddleOCR:** อ่านป้ายทะเบียนภาษาไทยแบบตรงๆ ได้ดีในภาพนิ่ง แต่ไวต่อมุมเอียงและเงาบนแผ่นป้าย
  * **YOLOv8 Fast-ALPR + CLAHE + Multi-Pass Tesseract OCR (tha+eng):** **(เลือกใช้เป็นโมเดลหลัก)**
* **ผลสรุปที่เลือกใช้:** **YOLOv8 + CLAHE + Tesseract Multi-Pass**
  * **เหตุผล:** YOLOv8 ทำหน้าที่ครอปเฉพาะกรอบแผ่นป้ายทะเบียนได้อย่างแม่นยำ 100% จากนั้นใช้ **CLAHE (Contrast Limited Adaptive Histogram Equalization)** ปรับความคมชัดและลบเงา ก่อนส่งให้อ่านด้วย Tesseract OCR ทำให้แยกแยะหมวดอักษร ตัวเลขทะเบียน และจังหวัด ได้แม่นยำสูง

---

### 1.3 🪪 การสแกนและอ่านข้อมูลบัตรประชาชน (Thai ID Card OCR)
* **โมเดลและเครื่องมือที่ประเมิน (ตามคำขอการทดลอง):**
  * **iApp Cloud API (`api.iapp.co.th`):** ให้ผลลัพธ์การสกัดข้อความบนบัตรภาษาไทยได้ครบถ้วน แต่ต้องพึ่งพาการเชื่อมต่ออินเทอร์เน็ตภายนอกและมีค่าบริการตามจำนวนครั้ง
  * **ThaiPersonalCardExtract (Perspective Warp + Top-Right 13-Digit ROI Crop):** **(นำแนวคิดมาพัฒนาเป็นเอนจินหลักแบบ Offline)**
  * **Thai-ID-OCR-Project:** โครงสร้างสำหรับภาพถ่ายรวม
* **ผลสรุปที่เลือกใช้:** **ROI Bounding Box Crop + Tesseract Digit Whitelist (`--psm 7 -c tessedit_char_whitelist=0123456789`)**
  * **เหตุผล:** นำเทคนิคการปรับขนาดภาพเป็นอัตราส่วนบัตรมาตรฐาน (1000x630px) แล้วใช้อัลกอริทึมเจาะกรอบสแกนเฉพาะพื้นที่ **Top-Right ROI (ตำแหน่งเลขบัตรประจำตัวประชาชน 13 หลัก)** บนบัตรประชาชน แล้วอ่านเฉพาะตัวเลข ทำให้ได้เลข 13 หลักที่ถูกต้อง 100% และทำงานได้แบบ Offline 100% โดยมี iApp API เป็นระบบสำรอง

## 2. 🏛️ โครงสร้างสถาปัตยกรรมระบบและองค์ประกอบสำคัญ (System Architecture & Isolation)

ระบบถูกออกแบบภายใต้หลักการ **Strict Data Isolation & Engine Separation** โดยแบ่งฐานข้อมูลและเอนจิน AI ออกเป็น 3 ส่วนอิสระจากกันอย่างเด็ดขาด:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        Telegram Mini App Frontend                      │
├───────────────────────────────────┬────────────────────────────────────┤
│ 📸 กล้องถ่ายรูปสด (Live WebRTC)   │ 📷 กล้องระบบมือถือ (Native Camera)  │
└─────────────────┬─────────────────┴─────────────────┬──────────────────┘
                  │                                   │
                  ▼                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                FastAPI Server Gateway (Mode-Based Routing)             │
├───────────────────┬───────────────────┬────────────────────────────────┤
│   โหมดสแกนใบหน้า  │ โหมดสแกนป้ายทะเบียน │    โหมดสแกนบัตรประชาชน        │
│   (mode='face')   │   (mode='plate')  │     (mode='idcard')            │
└─────────┬─────────┴─────────┬─────────┴───────────────┬────────────────┘
          │                   │                         │
          ▼                   ▼                         ▼
┌───────────────────┐ ┌───────────────────┐ ┌───────────────────────────┐
│ InsightFace AI    │ │ YOLOv8 + OCR AI   │ │ Top-Right ROI Digits OCR  │
└─────────┬─────────┘ └─────────┬─────────┘ └─────────────┬─────────────┘
          │                     │                         │
          ▼                     ▼                         ▼
┌───────────────────┐ ┌───────────────────┐ ┌───────────────────────────┐
│ ตาราง face_profiles│ │ตาราง license_plates│ │ตาราง warrants & id_cards  │
│ (Vector 512 มิติ) │ │(ทะเบียน/พ.ร.บ./คดี)│ │(เลขบัตร 13 หลัก/หมายจับ)  │
└───────────────────┘ └───────────────────┘ └───────────────────────────┘
```

### องค์ประกอบสำคัญของระบบ:
1. **ระบบกล้องคู่ไร้การเลือกไฟล์ (Dual Camera Architecture):**
   * **📸 ถ่ายรูปสด:** กล้องมองผ่านสดบนเว็บผ่าน WebRTC API
   * **📷 กล้องระบบ:** สลับไปใช้แอปกล้องหลักของโทรศัพท์มือถือโดยตรง
   * **(ถอดระบบเลือกไฟล์จากคลังภาพออก 100% ตามข้อกำหนด)**
2. **การปรับความเร็วประมวลผล AI (Server-Side Performance Downscaling):**
   * ย่อขนาดภาพที่อัปโหลดเข้ามาก่อนส่งเข้า AI ให้มีขนาดความกว้าง/สูงไม่เกิน 800px อัตโนมัติ ลดเวลาประมวลผลของ CPU เหลือไม่ถึง 1 วินาที
3. **การส่งรายงานผลเข้าแชทบอท Telegram (`/api/send_to_chat`):**
   * เมื่อสแกนพบหมายจับ ผู้ใช้กดปุ่ม `📩 ส่งข้อมูลเข้าแชทบอท` ระบบจะแนบ **รูปถ่ายจริงจากกล้อง** พร้อมสร้างข้อความรายงานรูปแบบ HTML สวยงามส่งตรงเข้าแชท Telegram ทันที

## 3. 🐳 โครงสร้างระบบเซิร์ฟเวอร์ Docker & Cloudflare Tunnel

ระบบรันอยู่บนสถาปัตยกรรมคอนเทนเนอร์ Docker (Multi-Container Architecture) ประกอบด้วย 3 คอนเทนเนอร์หลัก:

1. **`projectnew-web-1` (Web Application Server):**
   * รันด้วย Python 3.11 + FastAPI + Uvicorn ประมวลผลโมเดล AI ทั้งหมด
2. **`mysql-ai` (MySQL Database 8.0 Server):**
   * ฐานข้อมูลหลักของระบบ ทำหน้าที่เก็บตารางแยกทั้ง 3 ระบบ (`face_profiles`, `license_plates`, `warrants`, `id_cards`)
3. **`phpmyadmin-ai` (Database Management Web UI):**
   * เปิดพอร์ต `8080` ([http://localhost:8080](http://localhost:8080)) สำหรับผู้ดูแลระบบเข้าไปจัดการข้อมูลในฐานข้อมูล

### 🌐 การเชื่อมต่อเครือข่ายด้วย Cloudflare Quick Tunnel:
* ใช้โปรแกรม `cloudflared.exe` สร้างอุโมงค์ SSL/HTTPS ที่ปลอดภัยไปยัง Telegram Bot และ Telegram Mini App แบบอัตโนมัติ โดยรองรับการลงทะเบียน Telegram Webhook และ Telegram Menu Button โดยตรง

## 4. 📱 ขั้นตอนการเปิดใช้งาน Telegram Mini App

การใช้งานถูกออกแบบให้ราบรื่นผ่าน Telegram Application โดยไม่ต้องเปิดเบราว์เซอร์ภายนอก:

1. **ปุ่มเมนูล่างซ้าย (`MiniApp`):** กดที่ปุ่มเมนูมุมล่างซ้ายในหน้าแชทบอท Telegram เพื่อเปิด MiniApp สไลด์ขึ้นมาบนหน้าจอทันที
2. **ปุ่มกดในแชท (`🚀 เปิดระบบสแกน MiniApp`):** เมื่อกดคำสั่ง `/start` ระบบจะตอบกลับด้วยปุ่ม Native WebApp ในแชท ให้ผู้ใช้กดเปิด MiniApp ได้โดยตรง

      │
[ขั้นตอนที่ 3] กดถ่ายภาพด้วย "📸 ถ่ายรูปสด" หรือ "📷 กล้องระบบ"
      │

      ├─► โหมดใบหน้า   --> InsightFace ArcFace --> ค้นหาตาราง face_profiles

      │
[ขั้นตอนที่ 7] เจ้าหน้าที่กดปุ่ม "📩 ส่งข้อมูลเข้าแชทบอท" 
      │
[ขั้นตอนที่ 8] ระบบส่งภาพถ่ายจริงพร้อมข้อความรายงาน HTML เข้าห้องแชท Telegram ทันที

## 6. 📖 คู่มือการใช้งานสำหรับเจ้าหน้าที่ตำรวจ (User Guide)

1. เปิดแอป Telegram เข้าไปที่แชทบอท **`@Nontdanu_bot`**
2. กดปุ่มเมนู **`MiniApp`** ที่มุมล่างซ้าย หรือพิมพ์คำสั่ง `/start` แล้วกดปุ่ม **`🚀 เปิดระบบสแกน MiniApp`**
3. หน้าจอ Mini App จะเปิดขึ้นมา ให้เลือกโหมดการสแกน:
   * 👤 **สแกนใบหน้า:** สำหรับตรวจค้นบุคคลต้องสงสัย
   * 🚗 **สแกนป้ายทะเบียน:** สำหรับตรวจค้นรถยนต์ต้องสงสัย/รถชนแล้วหนี
   * 🪪 **สแกนบัตรประชาชน:** สำหรับตรวจสอบเลขบัตร 13 หลักกับฐานข้อมูลหมายจับ
4. กดปุ่ม **`📸 ถ่ายรูปสด`** หรือ **`📷 กล้องระบบ`** เพื่อทำการถ่ายภาพ
5. ตรวจสอบผลลัพธ์ หากพบบุคคลหรือรถที่มีหมายจับ สามารถกดปุ่ม **`📩 ส่งข้อมูลเข้าแชทบอท`** เพื่อบันทึกพยานหลักฐานและรายงานผลเข้าห้องแชททันที

## 7. 🛠️ เทคโนโลยีและเครื่องมือที่ใช้ในการพัฒนา (Tech Stack & Implementation)

* **Frontend:** HTML5, Vanilla JavaScript (ES6+), CSS3 (Modern Dark Glassmorphism Design), WebRTC Camera API, Telegram WebApp SDK
* **Backend Framework:** Python 3.11, FastAPI, Uvicorn (ASGI), Asyncio, Aiohttp, AioMySQL
* **AI Engine & Computer Vision:**
  * **InsightFace (ArcFace ResNet50 / ONNX Runtime):** สำหรับสกัดเวกเตอร์ใบหน้า 512 มิติ
  * **Ultralytics YOLOv8:** สำหรับตรวจจับตำแหน่งป้ายทะเบียนรถ
  * **OpenCV (cv2):** สำหรับการประมวลผลภาพ (CLAHE, Resize, Thresholding, Grayscale)
  * **PyTesseract (Tesseract-OCR):** สำหรับอ่านตัวอักษรและตัวเลขไทย/อังกฤษ
* **Database & Infrastructure:** MySQL 8.0, phpMyAdmin, Docker Compose, Cloudflare Tunnel (`cloudflared`), Telegram Bot API
